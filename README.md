# 🎮 Mini Games Hub

A fun collection of classic browser games built using **HTML, CSS, and JavaScript**. This project features an interactive home page where users can choose from three mini games and enjoy a smooth, responsive gaming experience.

## 🚀 Live Demo

🔗 **Play Here:** https://shwetha-c-hub.github.io/mini-games/

---

## 🎲 Games Included

### ❌ Tic Tac Toe
- Two-player gameplay (X vs O)
- Winner and draw detection
- Restart game option

### ✊ Rock Paper Scissors
- Play against the computer
- Random computer moves
- Live score tracking
- Reset game feature

### 🐍 Snake Game
- Control the snake using arrow keys
- Eat food to increase your score
- Collision detection
- Restart option after game over

---

## ✨ Features

- 🎨 Clean and modern pastel-themed UI
- 📱 Responsive layout
- 🖱️ Hover animations and interactive buttons
- 🏠 Home page with navigation to each game
- 💻 Built using vanilla JavaScript (no external libraries)

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
